# Changelog

## 0.5.0 — unreleased

- Add a working same-origin browser client for the v2 backend, with library/candidates, import, reader, figures, notes, research records, tasks, settings, and exports.
- Prepare a public monorepo with separate current, legacy, deployment, design, and documentation areas.
- Remove personal server defaults from the Mac source; support an explicit private HTTP host at build time.
- Add AGPL licensing, dependency notices, source packaging/audit tools, and a corresponding-source download for packaged servers.
- Add container/systemd examples and CI for the current backend, browser API client, and Mac app.

## 0.4.0

- Independent PostgreSQL backend, durable tasks, immutable file storage, versioned source evidence, and native research workflows.
- Source discovery, paper analysis, cross-paper comparison, figure correction, and v1 data migration.

## 0.3.x

- Native SwiftUI/PDFKit reading client, server-saved notes/groups/reading positions, and a v1 processing-engine adapter.
